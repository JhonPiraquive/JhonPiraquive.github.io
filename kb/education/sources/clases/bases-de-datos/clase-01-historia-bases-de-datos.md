# Clase 1 — Historia de las Bases de Datos

Consulta y síntesis de la evolución histórica hasta los sistemas actuales.

## Etapas a cubrir

1. **Antes de las BD (años 50–inicio 60):** archivos planos, cintas, procesamiento por lotes; duplicidad e inconsistencia.
2. **Era navegacional (años 60–principios 70):** modelo jerárquico (IBM IMS), modelo en red (CODASYL / IDS / IDMS); acceso por punteros.
3. **Modelo relacional (1970):** Edgar F. “Ted” Codd — *A Relational Model of Data for Large Shared Data Banks*; independencia de datos.
4. **Prototipos y SQL (años 70):** System R (IBM), INGRES (UC Berkeley); nacimiento de SQL; Oracle comercial (1977–79).
5. **Imperio relacional (años 80–90):** DB2, Oracle, SQL Server, PostgreSQL, MySQL; estandarización SQL; ER de Chen.
6. **Web y NoSQL (años 2000):** BigTable, Dynamo, MongoDB, Cassandra; documentos, clave-valor, columnas, grafos.
7. **Hoy:** NewSQL / SQL distribuido, bases en la nube, HTAP, vectoriales y convergencia de modelos.

## Enfoque pedagógico

Línea de tiempo visual (Mermaid `timeline`), comparación de modelos, ejemplos de PYME LATAM, práctica + quiz al cierre.
