Orientaciones de desarrollo
En el módulo de estudiantes se crearon las rutas, formularios, listas y acciones necesarias, Ahora, como reto, el estudiante creará el módulo docente. Para ello:  

Creará las rutas 
Creará el listado  
Creará el formulario  
Creará las acciones  
Nota: descargar el archivo anexo para ver las indicaciones. El estudiante entregará un proyecto de Vite Js con el lenguaje de programación React en un formato comprimido .zip en la fecha acordada o antes del vencimiento de esta. 

Criterios de evaluación
Desarrolla una experiencia de usuario efectiva en aplicaciones web. 
Todas las funcionalidades mencionadas son accesibles y operativas desde la interfaz de usuario. 
La interfaz de usuario es amigable, intuitiva y fácil de usar. 
Sigue las mejores prácticas de diseño de React y es atractiva visualmente. 
El proyecto está optimizado en términos de rendimiento para garantizar una experiencia de usuario fluida.
