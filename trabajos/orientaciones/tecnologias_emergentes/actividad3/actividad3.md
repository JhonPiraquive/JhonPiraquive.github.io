Orientaciones de desarrollo
El estudiante realizará peticiones http para la creación, edición, actualización y eliminación para el módulo de profesores a través de la API propuesta. Luego, entregará un proyecto de Vite Js con el lenguaje de programación React en un formato comprimido .zip. El proyecto será entregado en la fecha acordada o antes de la fecha de vencimiento especificada. 

Criterios de evaluación
Integración del enrutador para la navegación entre las interfaces del sitio administrativo. 
Todas las operaciones CRUD (Crear, Leer, Actualizar y Eliminar) funcionan correctamente. 
La creación de registros de profesor permite la entrada de información relevante y almacenarla de manera adecuada en la base de datos. 
La edición y actualización de registros de profesor refleja los cambios realizados de manera precisa en la base de datos. 
La eliminación de registros de profesor se hace de manera segura y sin errores. 
Se implementan validaciones para garantizar que los datos ingresados sean correctos y cumplan con los requisitos. 
El proyecto está optimizado en términos de rendimiento para garantizar una experiencia de usuario fluida.
